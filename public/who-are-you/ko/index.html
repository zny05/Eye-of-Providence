      먼저 고칠 것
      
          
      • 시간대와 IP
        • 시스템 시간대를 IP 위치에 맞추세요
        • Windows: 설정 → 시간 및 언어
        • macOS: 시스템 설정 → 일반 → 날짜 및 시간
      • 언어와 IP
        • 브라우저 언어 설정에서 IP 국가의 언어를 맨 위로 올리세요
        • 현지인처럼 보일 필요가 없다면 그대로 두세요
      • 시스템 언어와 IP
        • 시스템에 다른 언어 팩이 설치돼 있고, 글꼴과 음성에서 드러나요
        • 그 언어가 없는 시스템이나 가상 머신을 쓰세요
        • 아니면 시스템 언어와 맞는 지역을 고르세요
      • DNS 유출DNS 테스트
        • Clash / Mihomo: DNS를 fake-ip로 쓰거나 TUN 모드를 켜세요
        • V2Ray / Xray: DNS도 프록시로 보내세요
        • 브라우저: 보안 DNS를 켜세요
      • 분할 라우팅출구 IP 돋보기
        • 보통 프록시의 규칙에 따른 분할이에요. 통신사, 회사 네트워크, 보안 프로그램도 같은 방식으로 나눌 수 있어요
        • 프록시 때문이고 숨기고 싶다면: 글로벌 모드로
        • 네트워크가 나누는 거라면: 그대로 두세요
      • WebRTC 유출출구 IP 돋보기
        • 프록시 클라이언트에서 TUN 모드를 켜세요
        • 또는 브라우저에서 WebRTC를 제한하세요(Chrome: WebRTC Network Limiter)
      • 왕복 시간
        • 프록시를 거치면 이 구간이 반드시 생기고, 사이트는 그걸 잴 수 있어요
        • 가깝고 지연 시간이 짧은 서버를 고르면 차이가 줄어요
        • 가정용이나 모바일 출구가 데이터센터 IP보다 덜 의심받아요
      • 연결 지문
        • TCP 패킷은 시스템이 쓰기 때문에 브라우저도 안티디텍트 브라우저도 못 바꾸고, UA를 바꿔도 속일 수 없어요
        • 전체 터널 VPN이나 프록시를 쓰면 TCP가 서버의 것이 되고, 그 자체가 프록시의 증거예요
        • 캡처 도구, 회사 게이트웨이, 백신의 HTTPS 검사는 TLS와 HTTP/2 지문을 바꿔요. 꺼 보고 다시 확인하세요
      • 데이터센터 IPIP 품질 테스트
        • 가정용이나 모바일 회선 출구로 바꾸세요
        • 스트리밍, AI, 결제 사이트는 데이터센터 IP를 자주 막아요
      • UA와 실제 시스템
        • UA만 바꾸지 마세요: 그래픽 카드에서 들통나요
        • 여러 신원이 필요하면 안티디텍트 브라우저를 쓰세요
      • 조작된 환경
        • UA, 언어, 시간대를 바꾸는 확장 프로그램은 JavaScript가 읽는 값만 바꿔요. 요청 헤더와 그 아래 함수는 그대로예요
        • 다른 곳에 있는 것처럼 보이려면 시스템 자체의 언어와 시간대를 바꾸세요
        • 안티디텍트 브라우저라면 설정끼리 서로 맞는지 확인하세요
      • 안티디텍트 브라우저 흔적
        • 안티디텍트 브라우저에서 UA 버전을 엔진 버전과 맞추세요
        • 페이지의 navigator만 바꾸지 마세요: Worker에서도 같은 값이 읽혀야 해요(스크립트 주입이 아니라 커널 수준에서 바꾸기)
        • 시스템, 플랫폼, 그래픽 제조사는 한 세트로 고르고 섞지 마세요
      • 추적 가능한 지문
        • Brave를 쓰세요(지문을 자동으로 뒤섞어요)
        • 또는 Firefox에서 resistFingerprinting을 켜세요
        • 또는 Tor 브라우저를 쓰세요
      • 자동화 흔적
        • Selenium, Puppeteer 같은 자동화 도구를 끄고 새로고침하세요
      연결 방식
      • HTTP/3
        • 프록시가 UDP도 전달하게 하세요(Clash / Mihomo: TUN 모드, udp: true)
        • 방화벽에서 UDP 443을 허용하세요
        • 브라우저에서 QUIC이 꺼져 있지 않은지 확인하세요
      • ECH
        • 브라우저에서 보안 DNS(DNS over HTTPS)를 켜세요
        • 프록시: fake-ip를 끄거나, DNS가 HTTPS 레코드를 돌려주게 하세요
        • ECH를 지원하는 브라우저를 쓰세요: Chrome, Edge, Firefox
      • 양자 내성 암호
        • 브라우저를 업데이트하세요
        • 백신의 HTTPS 검사를 끄거나, 회사 프록시가 트래픽을 복호화하는지 물어보세요
      • WARP
        • Cloudflare WARP는 1.1.1.1 앱에서 켜고 끌 수 있어요
