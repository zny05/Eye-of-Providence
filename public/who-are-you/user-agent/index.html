        I care about
        
          
        Fix these first
        
          
        • Time zone vs IP
          • Set the system time zone to match the IP
          • Windows: Settings → Time & language
          • macOS: System Settings → General → Date & Time
        • Language vs IP
          • Put the IP country's language first in the browser
          • Not trying to pass as a local? Leave it
        • System language vs IP
          • The system has another language pack installed, and its fonts and voices show it
          • Use a system or virtual machine without those languages
          • Or pick a region that matches the system's language
        • DNS leakDNS Test
          • Clash / Mihomo: DNS with fake-ip, or TUN mode
          • V2Ray / Xray: send DNS through the proxy too
          • Browser: turn on Secure DNS
        • Split routingEgressLens
          • Usually a proxy's rule set; a mobile or company network, or security software, can split traffic the same way
          • If it's your proxy: switch to global mode to hide it
          • If the network splits it: there's nothing to change
        • WebRTC leakEgressLens
          • Proxy client: turn on TUN mode
          • Or limit WebRTC in the browser (Chrome: WebRTC Network Limiter)
        • Round trip
          • A proxy always adds this extra leg, and sites can measure it
          • A server closer to you, with lower latency, narrows the gap
          • Home or mobile exits draw less suspicion than data center IPs
        • Connection fingerprint
          • Your system writes the TCP packets: no browser or anti-detect browser changes them, and switching the user agent won't fool this
          • A full-tunnel VPN or proxy makes the TCP its server's, which itself shows a proxy
          • Capture tools, company gateways and antivirus HTTPS scanning change the TLS and HTTP/2 fingerprints: try turning them off
        • Data center IPIP Quality Test
          • Use a home or mobile exit instead
          • Streaming, AI and payment sites often block data center IPs
        • User agent vs system
          • Don't change only the user agent: the graphics card gives it away
          • Need several identities? Use an anti-detect browser
        • Tampered environment
          • Extensions that change the user agent, language or time zone only change what JavaScript reads; the request headers and the functions underneath stay as they were
          • To pass for elsewhere, change the system itself: its language and time zone
          • With an anti-detect browser, make sure its settings agree with each other
        • Anti-detect browser traces
          • In an anti-detect browser, pick a user agent version that matches its engine
          • Don't rewrite only the page's navigator: a Worker must read the same values (a change in the browser's core, not an injected script)
          • Pick system, platform and graphics vendor as one set, not mixed
        • Trackable fingerprint
          • Use Brave (it scrambles the fingerprint)
          • Or Firefox with resistFingerprinting
          • Or Tor Browser
        • Automation
          • Close Selenium, Puppeteer or other automation tools, then reload
        Connection
        • HTTP/3
          • Let the proxy carry UDP (Clash / Mihomo: TUN mode, udp: true)
          • Allow UDP 443 in the firewall
          • Check that QUIC isn't turned off in the browser
        • ECH
          • Turn on Secure DNS (DNS over HTTPS) in the browser
          • Proxy: turn off fake-ip, or have its DNS return HTTPS records
          • Use a browser that supports ECH: Chrome, Edge, Firefox
        • Post-quantum
          • Update the browser
          • Turn off HTTPS scanning in your antivirus, or ask whether the company proxy decrypts traffic
        • WARP
          • Cloudflare WARP: turn it on or off in the 1.1.1.1 app
