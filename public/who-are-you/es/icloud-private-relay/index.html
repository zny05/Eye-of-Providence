        Me interesa
        
          
        Arregla esto primero
        
          
        • Zona horaria e IP
          • Pon en el sistema la zona horaria de la IP
          • Windows: Configuración → Hora e idioma
          • macOS: Ajustes del Sistema → General → Fecha y hora
        • Idioma e IP
          • Pon primero en el navegador el idioma del país de la IP
          • ¿No necesitas pasar por local? Déjalo así
        • Idioma del sistema e IP
          • El sistema tiene instalado otro paquete de idioma, y sus fuentes y voces lo delatan
          • Usa un sistema o una máquina virtual sin esos idiomas
          • O elige una región que encaje con el idioma del sistema
        • Fuga de DNSTest de DNS
          • Clash / Mihomo: DNS con fake-ip, o modo TUN
          • V2Ray / Xray: manda también el DNS por el proxy
          • Navegador: activa el DNS seguro
        • Enrutamiento divididoEgressLens
          • Suele ser el reparto por reglas de un proxy; una operadora móvil, una red corporativa o un antivirus también pueden hacerlo
          • Si es tu proxy y quieres ocultarlo: cambia al modo global
          • Si lo reparte la red: no hay nada que cambiar
        • Fuga de WebRTCEgressLens
          • Cliente proxy: activa el modo TUN
          • O limita WebRTC en el navegador (Chrome: WebRTC Network Limiter)
        • Tiempo de ida y vuelta
          • Un proxy siempre añade este tramo, y las webs pueden medirlo
          • Un servidor más cercano, con menos latencia, reduce la diferencia
          • Las salidas domésticas o móviles levantan menos sospechas que las IP de centro de datos
        • Huella de conexión
          • Los paquetes TCP los escribe tu sistema: ni el navegador ni un navegador antidetección los cambian, y cambiar el user agent no engaña esto
          • Una VPN o proxy de túnel completo hace que el TCP sea de su servidor, lo que ya delata un proxy
          • Las herramientas de captura, las pasarelas de empresa y el escaneo HTTPS de los antivirus cambian las huellas TLS y HTTP/2: prueba a desactivarlos
        • IP de centro de datosTest de calidad de IP
          • Usa una salida doméstica o móvil
          • Los sitios de streaming, IA y pagos suelen bloquear los centros de datos
        • User agent y sistema
          • No cambies solo el user agent: la tarjeta gráfica te delata
          • ¿Necesitas varias identidades? Usa un navegador antidetección
        • Entorno manipulado
          • Las extensiones que cambian el user agent, el idioma o la zona horaria solo cambian lo que lee JavaScript; las cabeceras y las funciones de fondo siguen igual
          • Para parecer de otro sitio, cambia el propio sistema: su idioma y su zona horaria
          • Si usas un navegador antidetección, revisa que sus ajustes encajen entre sí
        • Rastros de navegador antidetección
          • En el navegador antidetección, elige una versión de user agent que encaje con su motor
          • No reescribas solo el navigator de la página: un Worker debe leer lo mismo (un cambio en el núcleo, no un script inyectado)
          • Elige sistema, plataforma y fabricante de la gráfica como un conjunto, sin mezclar
        • Huella rastreable
          • Usa Brave (mezcla la huella)
          • O Firefox con resistFingerprinting
          • O Tor Browser
        • Automatización
          • Cierra Selenium, Puppeteer u otra automatización y recarga
        Conexión
        • HTTP/3
          • Haz que el proxy transporte UDP (Clash / Mihomo: modo TUN, udp: true)
          • Permite UDP 443 en el firewall
          • Comprueba que QUIC no esté desactivado en el navegador
        • ECH
          • Activa el DNS seguro (DNS sobre HTTPS) en el navegador
          • Proxy: desactiva fake-ip, o haz que su DNS devuelva registros HTTPS
          • Usa un navegador compatible con ECH: Chrome, Edge, Firefox
        • Poscuántico
          • Actualiza el navegador
          • Desactiva el análisis HTTPS del antivirus, o pregunta si el proxy de tu empresa descifra el tráfico
        • WARP
          • Cloudflare WARP: actívalo o desactívalo en la app 1.1.1.1
