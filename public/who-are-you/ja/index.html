      • タイムゾーンと IP
        • システムのタイムゾーンを IP の場所に合わせる
        • Windows：設定 → 時刻と言語
        • macOS：システム設定 → 一般 → 日付と時刻
      • 言語と IP
        • ブラウザの言語設定で、IP の国の言語をいちばん上に
        • 現地の人に見せる必要がなければ、そのままで大丈夫
      • システムの言語と IP
        • システムに別の言語パックが入っていて、フォントや音声から分かります
        • その言語を入れていないシステムか仮想マシンを使う
        • あるいはシステムの言語に合う地域のサーバーを選ぶ
      • DNS 漏れDNS テスト
        • Clash / Mihomo：DNS を fake-ip に、または TUN モード
        • V2Ray / Xray：DNS もプロキシ経由に
        • ブラウザ：セキュア DNS をオン
      • スプリットトンネル（分流）出口照魔鏡
        • プロキシのルールによる分流がよくある原因です。携帯キャリア、社内ネットワーク、セキュリティソフトでも同じように分かれます
        • プロキシが原因で隠したいなら：グローバルモードに
        • 回線が分けているなら：そのままで
      • WebRTC 漏れ出口照魔鏡
        • プロキシのクライアントで TUN モードをオン
        • またはブラウザで WebRTC を制限（Chrome：WebRTC Network Limiter）
      • 往復時間
        • プロキシを通すとこの区間のぶん遅延が増え、サイトはそれを測れます
        • 近くて遅延の小さいサーバーにすれば、差は縮まります
        • 家庭用回線やモバイル回線の出口は、データセンターの IP より疑われにくい
      • 接続のフィンガープリント
        • TCP パケットは OS が書くので、ブラウザもアンチ検出ブラウザも変えられず、UA を変えてもごまかせません
        • フルトンネルの VPN やプロキシでは TCP がサーバーのものになり、それ自体がプロキシの証拠です
        • キャプチャツール、社内ゲートウェイ、ウイルス対策の HTTPS スキャンは TLS と HTTP/2 のフィンガープリントを変えます。切って試してください
      • データセンターの IPIP 品質テスト
        • 家庭用回線かモバイル回線の出口に変える
        • 動画配信・AI・決済のサイトは、データセンターの IP をよく拒否します
      • UA と実際のシステム
        • UA だけを変えない：GPU でばれる
        • 複数の身元が必要なら、アンチディテクトブラウザを
      • 環境の書き換え
        • UA・言語・タイムゾーンを変える拡張機能は、JavaScript が読む値しか変えません。リクエストヘッダーや内部の関数は元のまま
        • 別の場所に見せるなら、システムの言語とタイムゾーンそのものを変える
        • アンチディテクトブラウザなら、設定どうしが矛盾しないか確認
      • アンチディテクトブラウザの痕跡
        • アンチディテクトブラウザでは、ユーザーエージェントのバージョンをエンジンに合わせる
        • ページの navigator だけを書き換えない：Worker でも同じ値になるように（スクリプト注入ではなく、ブラウザ本体側の変更で）
        • システム・プラットフォーム・GPU ベンダーは一揃いで選び、混ぜない
      • 追跡できるフィンガープリント
        • Brave を使う（フィンガープリントを自動でかき混ぜる）
        • または Firefox で resistFingerprinting
        • または Tor Browser
      • 自動操作の痕跡
        • Selenium や Puppeteer などの自動操作ツールを止めて、再読み込み
      接続
      • HTTP/3
        • プロキシで UDP も通す（Clash / Mihomo：TUN モード、udp: true）
        • ファイアウォールで UDP 443 を許可
        • ブラウザで QUIC が無効になっていないか確認
      • ECH
        • ブラウザで「セキュア DNS」（DNS over HTTPS）をオン
        • プロキシ：fake-ip をやめるか、DNS が HTTPS レコードを返すようにする
        • ECH 対応のブラウザを使う：Chrome、Edge、Firefox
      • 耐量子暗号
        • ブラウザを更新
        • ウイルス対策ソフトの HTTPS スキャンをオフにするか、社内プロキシが通信を復号していないか確認
      • WARP
        • Cloudflare WARP：1.1.1.1 アプリでオン・オフを切り替え
