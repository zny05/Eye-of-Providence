        O que me importa
        
          
        Corrija isto primeiro
        
          
        • Fuso horário x IP
          • Coloque no sistema o fuso horário do IP
          • Windows: Configurações → Hora e idioma
          • macOS: Ajustes do Sistema → Geral → Data e Hora
        • Idioma x IP
          • Coloque em primeiro no navegador o idioma do país do IP
          • Não precisa se passar por local? Pode deixar
        • Idioma do sistema x IP
          • O sistema tem outro pacote de idioma instalado, e as fontes e vozes dele aparecem
          • Use um sistema ou máquina virtual sem esses idiomas
          • Ou escolha uma região que combine com o idioma do sistema
        • Vazamento de DNSTeste de DNS
          • Clash / Mihomo: DNS com fake-ip, ou modo TUN
          • V2Ray / Xray: mande o DNS pelo proxy também
          • Navegador: ative o DNS seguro
        • Roteamento divididoEgressLens
          • Costuma ser o roteamento por regras de um proxy; uma operadora móvel, uma rede corporativa ou um antivírus também podem dividir assim
          • Se é o seu proxy e você quer esconder: mude para o modo global
          • Se é a rede que divide: não há o que mudar
        • Vazamento WebRTCEgressLens
          • Cliente de proxy: ative o modo TUN
          • Ou limite o WebRTC no navegador (Chrome: WebRTC Network Limiter)
        • Tempo de ida e volta
          • Um proxy sempre adiciona esse trecho, e os sites conseguem medir
          • Um servidor mais perto, com menos latência, diminui a diferença
          • Saídas domésticas ou móveis levantam menos suspeita do que IPs de data center
        • Impressão da conexão
          • Quem escreve os pacotes TCP é o sistema: nem o navegador nem um navegador antidetecção os mudam, e trocar o user agent não engana isto
          • Uma VPN ou proxy de túnel completo deixa o TCP com o do servidor, o que já denuncia um proxy
          • Ferramentas de captura, gateways de empresa e a varredura HTTPS de antivírus mudam as impressões TLS e HTTP/2: experimente desligá-los
        • IP de data centerTeste de qualidade do IP
          • Use uma saída doméstica ou móvel
          • Sites de streaming, IA e pagamento costumam bloquear data centers
        • User agent x sistema
          • Não troque só o user agent: a placa de vídeo te entrega
          • Precisa de várias identidades? Use um navegador antidetecção
        • Ambiente adulterado
          • Extensões que trocam o user agent, o idioma ou o fuso só mudam o que o JavaScript lê; os cabeçalhos e as funções por baixo continuam iguais
          • Para parecer estar em outro lugar, mude o próprio sistema: idioma e fuso horário
          • Com um navegador antidetecção, confira se as configurações batem entre si
        • Rastros de navegador antidetecção
          • No navegador antidetecção, escolha uma versão de user agent que combine com o motor
          • Não reescreva só o navigator da página: um Worker precisa ler o mesmo (uma mudança no núcleo, não um script injetado)
          • Escolha sistema, plataforma e fabricante da placa como um conjunto, sem misturar
        • Impressão rastreável
          • Use o Brave (embaralha a impressão)
          • Ou o Firefox com resistFingerprinting
          • Ou o Tor Browser
        • Automação
          • Feche o Selenium, o Puppeteer ou outra automação e recarregue
        Conexão
        • HTTP/3
          • Faça o proxy levar UDP (Clash / Mihomo: modo TUN, udp: true)
          • Libere o UDP 443 no firewall
          • Confira se o QUIC não está desligado no navegador
        • ECH
          • Ative o DNS seguro (DNS sobre HTTPS) no navegador
          • Proxy: desligue o fake-ip, ou faça o DNS dele devolver registros HTTPS
          • Use um navegador com suporte a ECH: Chrome, Edge, Firefox
        • Pós-quântica
          • Atualize o navegador
          • Desligue a verificação HTTPS do antivírus, ou pergunte se o proxy da empresa descriptografa o tráfego
        • WARP
          • Cloudflare WARP: ligue ou desligue no app 1.1.1.1
