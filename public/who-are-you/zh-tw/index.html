      我在意
      
          
      先改這幾項
      
          
      • 時區與 IP
        • 把系統時區改成 IP 所在地的
        • Windows：設定 → 時間與語言
        • macOS：系統設定 → 一般 → 日期與時間
      • 語言與 IP
        • 在瀏覽器的語言設定裡，把 IP 所在國的語言排到第一
        • 不需要裝成當地人的話，可以不用管
      • 系統語言與 IP
        • 系統裝了其他語言套件，字型和語音會把它暴露出來
        • 換一個沒裝這些語言的系統或虛擬機器
        • 或選一個和系統語言一致的地區
      • DNS 外洩DNS 測試
        • Clash / Mihomo：DNS 用 fake-ip，或開 TUN 模式
        • V2Ray / Xray：讓 DNS 也走代理
        • 瀏覽器：開啟「安全 DNS」
      • 分流出口照妖鏡
        • 常見於代理依規則分流；電信業者、公司網路或安全軟體也會這樣
        • 是代理的分流、又不想被看出來：切到全域模式
        • 是網路自己分的：不用改
      • WebRTC 外洩出口照妖鏡
        • 代理用戶端開啟 TUN 模式
        • 或在瀏覽器裡限制 WebRTC（Chrome 安裝 WebRTC Network Limiter）
      • 往返延遲
        • 代理一定會多出這一段路，網站量得出來
        • 選離你更近、延遲更低的伺服器，差距會小一點
        • 住宅 IP 或行動網路的出口，比機房 IP 更不容易被懷疑
      • 連線指紋
        • TCP 封包由系統送出，瀏覽器和指紋瀏覽器都改不了，換 UA 騙不過這一項
        • 全域 VPN 或代理會讓 TCP 變成伺服器的系統，這本身就說明你在用代理
        • 封包擷取軟體、公司閘道、防毒軟體的 HTTPS 掃描會改掉 TLS 和 HTTP/2 指紋，可以關掉試試
      • 機房 IPIP 品質測試
        • 改用住宅 IP 或行動網路的出口
        • 串流、AI 和支付網站常會擋機房 IP
      • UA 與真實系統
        • 別只改 UA，顯示卡會露餡
        • 需要多個身分，就用指紋瀏覽器
      • 環境被竄改
        • 改 UA、語言、時區的擴充功能只改了 JS 讀到的那一份，請求標頭和底層函式還是原樣
        • 要偽裝，就直接改系統：系統語言和時區
        • 用指紋瀏覽器的話，確認它的各項設定彼此一致
      • 指紋瀏覽器痕跡
        • 在指紋瀏覽器裡，把 UA 版本選成和核心版本一致
        • 別只改頁面裡的 navigator，Worker 讀到的也要一樣（用核心層級的修改，別用注入腳本）
        • 系統、平台、顯示卡廠商選同一套，別混搭
      • 指紋追蹤
        • 改用 Brave（會自動打亂指紋）
        • 或在 Firefox 開啟 resistFingerprinting
        • 或使用 Tor 瀏覽器
      • 自動化痕跡
        • 關掉 Selenium、Puppeteer 等自動化工具，再重新整理頁面
      連線協定
      • HTTP/3
        • 讓代理轉送 UDP（Clash / Mihomo：TUN 模式，udp: true）
        • 防火牆開放 UDP 443
        • 確認瀏覽器沒關掉 QUIC
      • ECH
        • 瀏覽器開啟「安全 DNS」（DNS over HTTPS）
        • 代理：關掉 fake-ip，或讓它的 DNS 回傳 HTTPS 紀錄
        • 改用支援 ECH 的瀏覽器：Chrome、Edge、Firefox
      • 後量子加密
        • 更新瀏覽器
        • 關掉防毒軟體的 HTTPS 掃描，或問問公司的代理會不會解密流量
      • WARP
        • Cloudflare WARP：在 1.1.1.1 App 裡開關
