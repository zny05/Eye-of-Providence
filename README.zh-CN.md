# OpenStock

**告别昂贵的行情平台。** OpenStock 是一个免费、开源的市场平台替代方案：追踪价格、浏览全市场、深入了解公司信息。使用 [openstock-ods.vercel.app](https://openstock-ods.vercel.app)，或自行部署一份拥有所有功能的副本。

> ❤️ **13,000 多人免费使用 OpenStock。** 帮助我们保持免费：[每月从 5 美元起赞助](https://github.com/sponsors/ravixalgorithm/sponsorships?frequency=recurring&amount=5)，或阅读 [OpenStock 的运作方式](#赞助商)。

> [!NOTE]
> OpenStock 是社区共建的，不是券商。市场数据可能取决于供应商和你的设置而有所延迟。这里的内容不构成投资建议。

## 🔋 功能 <a name="功能"></a>

**市场**
- 覆盖七个市场的仪表板：美国、印度、德国、加拿大、澳大利亚、加密货币和外汇，包含指数脉搏、板块热力图、市场领涨股和热门新闻。
- 使用 ⌘K 搜索 Finnhub 覆盖的每一家交易所，并以浏览器标签页形式保持股票打开状态。

**股票页面**
- 带有绘图工具（趋势线、斐波那契、形状、文本）和全屏模式的 TradingView K 线图。
- 一次性选择指标（SMA、EMA、布林带、VWAP、RSI、MACD、随机指标、ATR），它们会保留在每个图表上。
- 财务数据、技术指标和公司概况。
- 来自 Reddit、X、新闻和 Polymarket（需 Adanos 密钥）的情绪分析。

**自选股和价格提醒**
- 最多 50 支股票的自选股，保存到你的账户。
- 高于或低于目标价格的价格提醒，每 5 分钟检查一次并通过电子邮件发送（实时模式下）。
- 每周一由 AI 撰写的新闻摘要，通过电子邮件发送。

**账户**
- 电子邮件和密码，以及配置后的 Google 和 GitHub 登录；密码重置和个人资料页面。
- 登录、注册和密码重置均受速率限制；重置密码会登出你的其他设备。

**社区**
- [更新日志](https://openstock-ods.vercel.app/changelog)，记录每位贡献者，[喜爱墙](https://openstock-ods.vercel.app/love)，以及应用中的更新横幅。

## 🤸 快速开始 <a name="快速开始"></a>

你需要 Node.js 22 LTS、一个 MongoDB 数据库（免费的 Atlas 集群，或下面的 [Docker 设置](#docker-setup)）和一个免费的 [Finnhub](https://finnhub.io) 密钥。

```bash
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
npm ci
cp .env.example .env         # 填入 MONGODB_URI、BETTER_AUTH_SECRET 和 FINNHUB_API_KEY
node scripts/check-env.mjs   # 检查你的 .env
npm run test:db              # 检查 MongoDB 连接
npm run dev                  # http://localhost:3000
```

欢迎邮件、价格提醒和每周摘要作为 [Inngest](https://www.inngest.com) 后台任务运行。在本地，请与应用一起启动 Inngest 开发服务器：`npx inngest-cli@latest dev`。

生产环境：`npm run build && npm start`。

## 🔐 环境变量 <a name="环境变量"></a>

所有变量均在 [`.env.example`](.env.example) 中带注释列出。重要的如下：

| 变量 | 是否必需 | 用途 |
|---|---|---|
| `MONGODB_URI` | 是 | 你的 MongoDB 数据库 |
| `BETTER_AUTH_SECRET` | 是 | 对会话进行签名。使用 `openssl rand -hex 32` 生成。生产环境下 Auth 拒绝在未设置时运行 |
| `BETTER_AUTH_URL` | 是 | 应用的公共 URL，用于身份验证回调和电子邮件中的链接 |
| `FINNHUB_API_KEY` | 是 | 市场数据。或将多个免费密钥用逗号分隔放入 `FINNHUB_API_KEYS`：它们会轮换，每个密钥每分钟增加 60 个请求 |
| `NEXT_PUBLIC_OPENSTOCK_DATA_MODE` | 否 | `cached`（每小时，默认）或 `realtime`（每 15 秒，带价格提醒）。构建时固定：更改后需重新构建 |
| `INNGEST_SIGNING_KEY`、`INNGEST_EVENT_KEY` | 生产环境 | 后台任务：欢迎邮件、价格提醒和每周摘要 |
| `NODEMAILER_EMAIL`、`NODEMAILER_PASSWORD` | 否 | 通过 Gmail 发送电子邮件，使用应用密码。未配置时，电子邮件将被跳过 |
| `GEMINI_API_KEY`（或 MiniMax 或 Siray） | 否 | AI 撰写的欢迎邮件和新闻摘要 |
| `ADANOS_API_KEY` | 否 | 股票页面上的情绪卡片 |
| `KIT_API_KEY`、`KIT_API_SECRET`、`KIT_WELCOME_FORM_ID` | 否 | Kit 中的每周新闻通讯 |
| `GOOGLE_CLIENT_ID` / `_SECRET`、`GITHUB_CLIENT_ID` / `_SECRET` | 否 | 社交登录。回调：`<BETTER_AUTH_URL>/api/auth/callback/google` 和 `/github` |

`NEXT_PUBLIC_FINNHUB_API_KEY` 仍可作为 Finnhub 密钥的名称使用。没有密钥会发送到浏览器。

## 🐳 自托管 <a name="自托管"></a>

### Docker Compose <a name="docker-setup"></a>

一起运行 OpenStock 和 MongoDB。MongoDB 仅在 Docker 网络内可达；不会在你的机器上发布。

1. 填写 `.env`（见上文）。对于捆绑的数据库，选择一个密码，并在两处都使用它。字母和数字最简单；`@ : / ? #` 必须在 URI 中百分比编码。
   ```env
   MONGO_ROOT_PASSWORD=change-me
   MONGODB_URI=mongodb://root:change-me@mongodb:27017/openstock?authSource=admin
   ```
2. 启动：`docker compose up -d --build`
3. 打开 http://localhost:3000

镜像构建不需要密码：每个变量在容器启动时读取，除了 `NEXT_PUBLIC_OPENSTOCK_DATA_MODE`，Compose 会从 `.env` 传递给构建。数据存储在 `mongo-data` 卷中，MongoDB 密码仅在首次创建该卷时应用。

### 预构建镜像

每次推送到 `main` 都会为 amd64 和 arm64 发布 `ghcr.io/open-dev-society/openstock`，标记为 `latest`、`sha-<commit>`，以及每个发布版本（例如 `2026.10.18`）。要使用它，在 `docker-compose.yml` 中将 `openstock` 下的 `build:` 替换为：

```yaml
    image: ghcr.io/open-dev-society/openstock:latest
```

然后运行 `docker compose pull && docker compose up -d`。预构建镜像以缓存模式运行；如需实时模式，请自行构建。

### Railway <a name="deploy-on-railway"></a>

OpenStock 提供 [`railway.json`](railway.json) 来构建 `Dockerfile`，对 `/sign-in` 进行健康检查并在失败时重启。上面的模板会设置一切；如需手动操作：

1. 创建项目并添加一个 **MongoDB** 数据库（`+ New → Database → MongoDB`）。
2. 从此仓库添加服务（`+ New → GitHub Repo`）。
3. 在服务的 **Variables** 中，设置：
   ```env
   MONGODB_URI=${{MongoDB.MONGO_URL}}
   BETTER_AUTH_SECRET=${{secret(32)}}
   BETTER_AUTH_URL=https://${{RAILWAY_PUBLIC_DOMAIN}}
   FINNHUB_API_KEY=your_finnhub_key
   GEMINI_API_KEY=your_gemini_api_key
   INNGEST_SIGNING_KEY=your_inngest_signing_key
   INNGEST_EVENT_KEY=your_inngest_event_key
   NODEMAILER_EMAIL=youraddress@gmail.com
   NODEMAILER_PASSWORD=your_gmail_app_password
   ```
4. 在 **Settings → Networking** 下，生成公共域并重新部署。

对于后台任务，在 [Inngest 控制面板](https://app.inngest.com) 中添加你的 Railway 域名作为应用，指向 `https://<your-domain>/api/inngest`。要开启实时模式，还需设置 `NEXT_PUBLIC_OPENSTOCK_DATA_MODE=realtime`；Railway 会将其传递给构建。

### Vercel

导入仓库，将上述变量设置为 Production，并连接 Inngest（其 Vercel 集成会设置两个密钥）。[`vercel.json`](vercel.json) 将函数固定到孟买（`bom1`），靠近托管数据库；将其更改为离你最近的区域。

## 📡 工作原理与集成 <a name="工作原理与集成"></a>

- **Finnhub**：搜索、行情、公司概况和新闻。响应被缓存并共享（一小时，或在实时模式下每 15 秒），带有超时和密钥池，因此缓慢的上游永远不会让页面挂起。
- **TradingView**：图表、热力图、财务、技术指标和概况小部件。
- **Adanos**（可选）：股票页面上的情绪卡片。
- **Better Auth 与 MongoDB**：账户和会话。页面和服务器操作在服务器上检查会话；中间件仅将未登录的访问者重定向。
- **Inngest** 运行后台任务：

  | 任务 | 时间 |
  |---|---|
  | AI 个性化欢迎邮件 | 注册时 |
  | 价格提醒检查 | 每 5 分钟，实时模式下 |
  | 每周新闻摘要（Kit 广播） | 每周一 09:00 UTC |

- **电子邮件**：Nodemailer (Gmail) 发送欢迎、提醒和密码重置邮件；Kit 发送每周摘要。

## 🤝 贡献指南 <a name="贡献指南"></a>

你很欢迎。无论你是学生、自学开发者还是经验丰富的工程师，贡献都受欢迎。

1. 从 [好第一个问题](https://github.com/Open-Dev-Society/OpenStock/issues?q=is%3Aopen+label%3A%22good+first+issue%22) 中选择一个，或开一个问题来讨论一个想法或错误。
2. Fork 仓库，从 `main` 分支创建分支，然后运行 `npm ci` 和 `cp .env.example .env`。
3. 保持拉取请求专注：新逻辑附带一个测试，UI 更改附带一个截图。
4. 在开启之前，运行 `npm test`、`npx tsc --noEmit` 和 `npm run lint`。

每个合并的拉取请求，以及每个导致修复的问题，都会在 [更新日志](https://openstock-ods.vercel.app/changelog) 和下方记录。友善，指导初学者，不设门槛：这是 Open Dev Society 的方式。参与受 [行为准则](CODE_OF_CONDUCT.zh-CN.md) 保护。

## 🌱 Open Dev Society 宣言 <a name="宣言"></a>

我们生活在一个知识被付费墙隐藏的世界。工具被订阅锁定。信息被偏见扭曲。新来者被告知他们不够“好”以无法建立。

我们相信有一条更好的道路。

- **我们的信念：** 技术应属于每个人。知识应开放、免费且可访问。社区应以信任而非门槛欢迎新来者。
- **我们的使命：** 构建免费的开源项目，带来真正的改变：专业人士和学生可以无障碍使用的工具，学习永远免费的知识平台，引导而非评判每个初学者的社区，运行在透明而非利润之上的资源。
- **我们的承诺：** 我们永远不会锁定知识。我们永远不会收取访问费。我们永远不会为了金钱而出卖信任。我们运行在透明度、捐赠和社区力量之上。
- **我们的号召：** 如果你曾感到自己不属于这里，难以找到免费资源，或想构建有意义的东西，你属于这里。

因为未来属于那些公开构建它的人。
